# Runnable examples

These snippets complement `uv run pytest` by showing minimal **repoman.yaml** stubs and CLI
commands. They use **placeholders only** (`example.com`, disposable paths)—never paste real
tokens or private URLs here.

Prerequisites:

- Repository clone with `uv sync --all-groups`
- Commands run from repository root unless a subfolder README says otherwise

See subfolders:

- [`local-plan/`](local-plan/) — smoke `repoman config validate`, `doctor`, `local plan`/`sync`
  against toy paths
